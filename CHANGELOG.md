# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - Initial Release

### Added
- **Core Engine**: Fully functioning client-side carbon calculation logic in `carbon.js`.
- **Interactive Quiz**: 4-step onboarding quiz collecting data on commute, home energy, food, and lifestyle habits.
- **Dynamic Dashboard**: Visualizations of the user's carbon footprint, compared to the global average.
- **AI Carbon Coach**: Deep integration with Google Gemini Pro 1.5 to provide contextual, personalized, and actionable climate advice.
- **Community Forest**: A shared visualization reflecting the collective actions of all users on the platform.
- **Action Lab**: A module allowing users to explore and commit to real-world carbon reduction activities.
- **Shareable Cards**: Dynamic generation of share cards allowing users to showcase their commitment.
- **Security & CI/CD**: Full secrets separation, `config.js` injection, and automated GitHub Actions deployment pipelines for preview and production environments.
